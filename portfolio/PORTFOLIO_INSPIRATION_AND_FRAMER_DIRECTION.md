# Victory Chukwuma Portfolio Inspiration and Framer Direction

## Decision

The portfolio should feel like an authored product-design publication, not a résumé with thumbnails and not a generic UX case-study CMS.

The best direction is a restrained editorial shell with project-specific art direction inside it:

- A clear point of view on the homepage
- Five deliberately ranked projects
- Fast evidence and outcomes before long explanations
- A shared typographic and navigation system
- A different narrative device for each project
- Enough personality to feel unmistakably like Victory
- Minimal motion used to explain relationships, not decorate the page

The Framer template should be treated as a source of layout mechanics, responsive behaviour, and interaction references. It should not become the finished identity.

---

# 1. What the best personal portfolios do

## 1.1 They make the designer's value obvious before the first project

A weak portfolio starts with a job title. A strong portfolio starts with an argument.

Richard Choi establishes experience, domains, awards, patents, and the full product lifecycle on the homepage. Simon Pan leads each project with ownership and measured outcomes. Two Actual Eyes states a specific advantage: designing systems and shipping the code that runs them.

For Victory, the equivalent argument is:

> I bring structure to products with many moving parts, from commercial platforms to early-stage services and complex interaction systems.

This should appear before a recruiter encounters project cards.

## 1.2 They describe projects as transformations

The best project titles explain what changed:

- Simon Pan: redesigning Uber pickup and reducing wait time and pickup error
- Richard Choi: producing an investor-ready AI product in four weeks
- Ronald Lopez: rebuilding a portfolio as a design system
- Travis Lydon: turning a static portfolio into a living product surface

Victory's project titles already support this pattern:

- Skydd: From focused insurance product to eight-product protection platform
- LOQD: Designing trust into a real-world custody service
- Meelow: Safety without surveillance
- Coupon: From 141 screens to one coherent investment system
- Juju Games: Building a game studio before building a startup became the story

## 1.3 They reveal evidence early

Strong portfolios do not ask the viewer to read several sections before understanding scale or impact.

The first screen of every Victory case study should contain:

- The transformation in one sentence
- Victory's role
- Scope or product surface
- One to three verified proof points
- A representative visual or system map

The viewer should understand why the project matters within 20 seconds.

## 1.4 They are highly scannable without becoming shallow

Long case studies work when they provide entry points:

- Section labels
- Short summaries
- Pull quotes
- Large evidence captions
- Before-and-after comparisons
- Sticky table of contents where useful
- Occasional decision cards

Ronald Lopez is a useful reference here. The portfolio research, principles, tokens, components, and implementation are presented as a clear system rather than an uninterrupted essay.

## 1.5 They use personality as authorship, not decoration

Personality comes from language, rhythm, curation, and specific details. It does not require animated cursors, floating blobs, or a novelty interaction on every screen.

The site should sound like Victory: observant, direct, systems-minded, ambitious, and comfortable moving between product detail and business reality.

# 2. Personal website reference library

## Tier A: Direct structural references

### 1. Simon Pan

**URL:** https://simonpan.com/

**Why it matters:** One of the clearest examples of outcome-led product-design storytelling. Project cards communicate ownership and measurable results before the visitor opens a case study.

**Borrow:**

- Project title plus transformation
- Metrics on the project card
- Clear role language
- Case studies organised around consequential decisions

**Do not borrow:**

- The older visual styling
- Very long linear storytelling without stronger modern navigation

**Best application:** Skydd and Coupon.

### 2. Richard Choi

**URL:** https://www.richardesign.com/

**Why it matters:** The homepage establishes authority before presenting projects. It combines a professional thesis, proof metrics, selected work, range, and personal/community credibility.

**Borrow:**

- Credibility strip near the top
- Numbered project index
- One-line project outcomes
- Clear separation between current work, history, and broader identity

**Do not borrow:**

- Too many capability categories
- Award-heavy positioning that Victory cannot yet support with equivalent evidence

**Best application:** Homepage hierarchy and Juju retrospective.

### 3. Ronald Lopez

**URL:** https://www.ronglopez.com/projects/ronglopez-portfolio.html

**Why it matters:** Treats the portfolio itself as a product and design system. Long content remains legible through sectioning, navigation, and explicit principles.

**Borrow:**

- A visible page contents system
- Section numbering
- Decision principles
- Process represented as a system
- Restrained accent colour

**Do not borrow:**

- Making the portfolio process itself a major public case study
- Over-explaining implementation foundations to non-technical recruiters

**Best application:** All long case studies, especially Skydd and Coupon.

### 4. Two Actual Eyes

**URL:** https://twoactualeyes.com/work/

**Why it matters:** Leads with a differentiated thesis and uses compact proof labels such as sole designer, two-sided product, and design system.

**Borrow:**

- Strong first-person thesis
- Compact proof tags on project entries
- Clear division between featured work and experiments or earlier work

**Do not borrow:**

- Technical-builder positioning that is not central to Victory's current story

**Best application:** Homepage opening and project-card metadata.

### 5. Travis Lydon

**URL:** https://travislydon.com/project/personal-portfolio-platform

**Why it matters:** Treats content structure, filtering, accessibility, and iteration as parts of the product rather than afterthoughts.

**Borrow:**

- Accessible media behaviour
- Durable content architecture
- Tags used for orientation rather than keyword decoration
- Deep links to shareable project sections if technically practical

**Do not borrow:**

- Dense filtering for only five main projects
- Masonry layouts that weaken project hierarchy

**Best application:** Site-system planning and media behaviour.

# 3. Framer template research

## Evaluation criteria

Every template was assessed against the needs of this portfolio:

1. Can it express a strong professional thesis?
2. Can recruiters scan it quickly?
3. Can projects have different structures and visual characters?
4. Does it support long-form product thinking?
5. Is the mobile version credible?
6. Can the template be stripped back without fighting its construction?
7. Does it avoid the familiar “Framer portfolio template” look?
8. Is it useful as a style guide even if the final site is custom-built?

## Shortlist

### 1. Baseframe

**URL:** https://www.framer.com/marketplace/templates/baseframe/

**Price:** Free

**Best quality:** Case-study reading structure.

Baseframe uses an editorial, grid-based system and is explicitly organised around guiding visitors through thinking rather than displaying thumbnails. Its typography, hierarchy, and long-form mechanics make it the strongest structural reference.

**Use from it:**

- Case-study grid
- Section rhythm
- Typographic hierarchy
- Responsive long-form behaviour
- Project navigation

**Reject from it:**

- Identical CMS structure for every project
- Brutalism if it becomes visually cold
- Custom cursor or effects that reduce clarity

**Verdict:** Best structural base, but not the final visual identity.

### 2. Mika Kujo

**URL:** https://www.framer.com/marketplace/templates/mika-kujo/

**Price:** $15

**Best quality:** Calm editorial character.

Mika Kujo uses a clean grid, strong typography, subtle sticky interaction, and very little decorative motion. It feels considered without becoming sterile.

**Use from it:**

- Editorial proportion
- Sticky text and media relationships
- Quiet movement
- Confident typography
- Project-first navigation

**Reject from it:**

- Art-director assumptions that privilege imagery over product reasoning
- A uniform project layout

**Verdict:** Best primary visual-style reference.

### 3. Portfolder

**URL:** https://www.framer.com/marketplace/templates/72319/

**Price:** $49

**Best quality:** A memorable organising metaphor.

The folder-tab navigation, paper grain, and editorial language create a strong authored identity.

**Use from it:**

- A sense of projects as files, evidence, and working material
- Tabs or index markers
- Paper and annotation cues
- A separate Playground area

**Reject from it:**

- Literal folder styling across the entire site
- Stamp effects on every asset
- Anything that makes the work feel nostalgic rather than current

**Verdict:** Excellent inspiration for micro-details and the project index, but too concept-heavy as the complete base.

### 4. Paige Holden

**URL:** https://www.framer.com/marketplace/templates/paige-holden/

**Price:** Free

**Best quality:** A practical product-designer foundation.

It includes a strong homepage, project CMS, case-study pages, responsive behaviour, and a clean editorial grid.

**Use from it:**

- Responsive foundation
- Homepage section order
- Project-detail mechanics
- Reusable cards

**Reject from it:**

- Services, testimonials, and conversion sections unless they support an actual goal
- Generic UX portfolio language

**Verdict:** Best no-cost practical fallback if Baseframe proves difficult to adapt.

### 5. FORME by Tungsten

**URL:** https://www.framer.com/marketplace/templates/forme-by-tungsten/

**Price:** $59

**Best quality:** Warm editorial restraint.

Warm paper tones, expressive serif headings, and restrained layouts offer a good alternative to the cold monochrome product-design portfolio.

**Use from it:**

- Warm neutral canvas
- Serif and sans-serif contrast
- Image scale
- Small set of shared styles

**Reject from it:**

- Brand-studio framing
- A project detail model designed mainly around title, client, summary, and cover image

**Verdict:** Strong colour and typography reference, weaker product-case-study structure.

### 6. Aster Bloom

**URL:** https://www.framer.com/marketplace/templates/aster-bloom/

**Price:** $29

**Best quality:** Immersive, image-led editorial pages with flexible CMS collections.

**Use from it:**

- Full-bleed visual pacing
- Archive behaviour
- Refined transitions
- Generous negative space

**Risk:** Product screenshots could become decorative rather than explanatory.

**Verdict:** Useful for visual pacing, not the main structural base.

### 7. Noah Vesper

**URL:** https://www.framer.com/marketplace/templates/noah-vesper/

**Price:** $99

**Best quality:** Strong case-study completeness and recruiter orientation.

The template is built around overview, challenge, approach, solution, results, and reflection, and includes accessibility and responsive details.

**Use from it:**

- Recruiter scan path
- Metadata and outcomes
- Responsive polish
- Semantic structure

**Reject from it:**

- The same six-section formula for all projects
- Prewritten content patterns that could flatten Victory's voice
- Decorative physics and cursor effects

**Verdict:** A good checklist, not a good identity.

### 8. Lesmana

**URL:** https://www.framer.com/marketplace/templates/lesmana/

**Price:** $129

**Best quality:** Senior product-designer positioning and extensive commercial setup.

**Use from it:**

- Credibility framing
- SEO structure
- Prelaunch checklist
- Polished responsive foundations

**Risk:** Expensive, conversion-oriented, and visually close to the generic premium UX-template market.

**Verdict:** Not recommended as the main reference.

### 9. Jonas

**URL:** https://www.framer.com/marketplace/templates/jonas/

**Price:** $149

**Best quality:** Clean implementation, responsive behaviour, and light/dark mode.

**Risk:** A one-page minimalist model does not provide enough narrative range for Victory's projects. Absolute-positioning-heavy construction may also be less pleasant to restructure.

**Verdict:** Too expensive and too generic for this portfolio.

### 10. Karoo

**URL:** https://www.framer.com/marketplace/templates/karoo/

**Price:** Free

**Best quality:** Structured case studies and elegant visual presentation.

**Risk:** Designed for brand projects, which encourages visual galleries rather than product logic.

**Verdict:** Good visual reference, poor primary base.

# 4. Recommended design formula

## Primary source

Use **Mika Kujo** as the main visual-style reference.

It offers the right balance of:

- Editorial maturity
- Calm typography
- Subtle interaction
- Clean grid discipline
- Enough neutrality for project-specific art direction

## Structural source

Use **Baseframe** as the case-study and responsive-layout reference.

## Personality source

Borrow selectively from **Portfolder**:

- Indexed tabs
- Evidence labels
- Paper or annotation details
- A sense of opening a working file

## Warmth source

Borrow the paper-tone and serif/sans contrast from **FORME** or Aster Bloom, without adopting their brand-portfolio structure.

## Practical fallback

If one template must be remixed directly, begin with **Baseframe** because it is free, structurally closest to the content, and easiest to test without committing money.

Do not populate its CMS and call the site complete. Use it to study breakpoints, type scale, grid, section rhythm, and interactions, then design the actual pages around Victory's content.

## Global pages

### Home

1. Thesis
2. Current roles: Product Designer at Skydd and building LOQD
3. Selected work in deliberate order
4. Short evidence strip
5. Working principles
6. Earlier work and Juju Games
7. About preview
8. Contact

### Work index

An optional compact index for repeat visitors. Use rows rather than another large card grid.

Columns:

- Project
- Transformation
- Role
- Signal
- Year or status

### About

- Short professional story
- How Victory works
- Career timeline
- CV link
- Personal detail with restraint
- Contact

### Playground

Experiments, visual studies, smaller work, and selected incomplete ideas. Coupon should not live here now that it supports a real case study.

### Project pages

Each project receives its own page and narrative system.

# 6. Unique case-study identities

## Skydd: Expansion map

**Page behaviour:** Show the platform widening from a focused product into eight products across web, mobile, and marketing.

**Signature device:** A horizontal or vertically unfolding architecture map.

**Visual tone:** Precise, expansive, commercial.

**Evidence rhythm:** Before and after, product architecture, cross-surface flows, shipped outcomes.

## LOQD: Service journey

**Page behaviour:** Move between customer experience, physical custody, and operational responsibility.

**Signature device:** A three-lane journey for customer, custody item, and operator.

**Visual tone:** Tactile, trustworthy, grounded in the real world.

**Evidence rhythm:** Research insight, service blueprint, risk decision, physical and digital proof.

## Meelow: Relationship and state model

**Page behaviour:** Explain directional permissions and changing states between people.

**Signature device:** Interactive or animated relationship diagrams.

**Visual tone:** Calm, humane, privacy-aware.

**Evidence rhythm:** Rule, consequence, sender state, receiver state.

## Coupon: Audit file

**Page behaviour:** Reveal how a large financial product moved from ambiguity to coherence.

**Signature device:** 141 → 115 transformation, product-domain map, audit annotations, and canonical flow.

**Visual tone:** Analytical, structured, evidence-led.

**Evidence rhythm:** Finding, decision, structural change, resulting state.

## Juju Games: Studio archive

**Page behaviour:** A compact retrospective constructed from public press, studio work, selected game UI, production material, and the chronology of co-building.

**Signature device:** Timeline or archival contact sheet.

**Visual tone:** Energetic, historical, builder-focused.

**Evidence rhythm:** Moment, contribution, artifact, external validation.

Juju does not need a Figma file. Its credibility comes from external evidence and the continuity of Victory's builder instinct.

# 7. Visual-system recommendation

## Typography

Use two families:

- A restrained grotesk or neo-grotesk sans for interface, metadata, and body text
- A characterful but readable serif for large statements, project titles, and occasional pull quotes

Avoid a highly stylised display font. The work is already complex.

## Colour

Global palette:

- Warm off-white rather than pure white
- Near-black rather than absolute black
- One muted personal accent used sparingly

Project palettes can change inside case studies:

- Skydd: cool protection and growth tones
- LOQD: deep neutral, material, custody colours
- Meelow: calm greens or blues with explicit state colours
- Coupon: paper, graphite, audit red or amber
- Juju: stronger studio and game colours

## Grid

- Twelve-column desktop grid
- Generous outer margins
- Body-copy width capped for reading
- Full-width visual breaks
- Clear alignment between metadata and narrative

## Motion

Use motion for:

- Page transitions
- Revealing project relationships
- Moving between before and after
- Showing a system expanding
- Demonstrating state changes

Avoid:

- Cursor followers
- Constant parallax
- Scroll hijacking
- Long intro animations
- Movement that delays reading

## Interface details

- Small numbered project labels
- Evidence tags such as SHIPPED, SYSTEM, RESEARCH, VERIFIED, EARLY STAGE
- Sticky project index on desktop
- Progress indicator for long cases
- Previous and next project navigation
- Resume link visible from every page
- Text-first accessibility and descriptive captions

---

# 8. What to reject

The research makes several tempting directions easy to rule out:

- A universal six-section CMS template for every project
- A dark, glossy “senior product designer” theme with floating device mockups
- A homepage dominated by a portrait and generic bio
- Skill bars or software proficiency meters
- Excessive services, testimonials, and conversion copy for a job-focused portfolio
- Process theatre such as generic double-diamond diagrams
- Case studies that start with research rituals before establishing the actual problem
- Animation as proof of craft
- Hiding strategic or operational work behind polished final screens
- Presenting Juju like an incomplete UX case study simply because no Figma file exists

---

# 9. Final recommendation

Build a custom portfolio in Figma using this combination:

> Mika Kujo's editorial calm + Baseframe's case-study mechanics + Portfolder's authored details + Victory's project-specific narratives.

If a Framer template is purchased, **Mika Kujo at $15** provides the best value as a visual and interaction reference.

If a template is remixed as a working prototype, **Baseframe** is the strongest first choice because it is free and already handles the hardest generic problem: long-form case-study readability.

The final website should not be recognisable as either template.

Its identity should come from the central idea that runs through Victory's work:

> Complex products become usable when their underlying system becomes clear.
