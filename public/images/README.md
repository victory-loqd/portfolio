# Exported Portfolio Assets Directory

Drop your exported Figma PNG / WebP / SVG files directly into this directory (`public/images/`).

Each case study and retrospective looks for its corresponding filename in this directory. 
- **If the file exists:** Next.js renders your high-resolution asset immediately.
- **If the file is not yet exported:** The component renders an ultra-crisp blueprint placeholder with exact dimensions, asset ID, title, and copyable filename.
